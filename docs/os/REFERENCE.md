# BOOK AND READING RESOURCES

## Core OS Development Books

These are the most recommended textbooks and practical guides for learning how operating systems work and how to build one:

Operating Systems: Three Easy Pieces (Arpaci-Dusseau & Arpaci-Dusseau) – Free online, conversational style, covers virtualization, concurrency, and persistence. Great for theory before diving into code.[1][2][3]

Operating Systems: From 0 to 1 (Tu Tran Minh) – Practical, step-by-step guide to building a simple OS from scratch, including bootstrapping and kernel basics.[2][4]

The Little Book about OS Development – Short, beginner-friendly introduction to OS dev concepts and x86 basics.[2][5]

Modern Operating Systems (Tanenbaum) – Classic textbook for deep theoretical understanding of OS design and implementation.[1][2][3]

Operating System Concepts (Silberschatz, Galvin, Gagne) – Widely used university textbook, excellent for foundational OS principles.[1][3][4]

Understanding the Linux Kernel (Bovet & Cesati) – For when you want to understand how Linux itself is structured, useful for projects and customization.[1][3]

Linux Kernel Development (Robert Love) – Practical guide to writing and modifying Linux kernel code.[3][4]

## Tutorials and Online Resources

These are free, hands-on resources that complement the books:

OS Dev Wiki – The central hub for OS development tutorials, FAQs, and community knowledge.[1][2]

cfenollosa/os-tutorial (GitHub) – Step-by-step tutorial to write a tiny OS in C and assembly.[5]

Bran’s Kernel Development – Tutorial series on writing a hobby OS kernel.[5]

Baking Pi – Operating System Development (University of Cambridge) – Learn OS dev on a Raspberry Pi, which is highly relevant for Cyberdeck builds.[5]

xv6: A Simple Unix-like Teaching Operating System (MIT) – Source code and documentation for a minimal Unix-like OS, great for study and experimentation.[3]

Linux From Scratch – Build your own Linux distribution from source, excellent for understanding the full stack.[5]

## Cyberdeck-Specific Reading

Since you’re building or using a Cyberdeck, these books and guides focus on the hardware and portable computing side:

DIY Portable Computer Projects: Build and Program Your Own Cyberdeck – Shows how to turn single-board computers (like Raspberry Pi) into smart, portable systems.[6]

How to Create Your Cyberdeck (Lani Kasaa) – Covers hardware selection, power systems, input devices, and what you can do with a Cyberdeck.[7]

Cyberdeck Build Guide — The Cyberdeck Cafe – Community-vetted parts list and build advice to avoid “techno junk.”[8]
## Suggested Learning Path:

Start with theory: Read Operating Systems: Three Easy Pieces or Operating System Concepts for foundational knowledge.[2][3][4]

Build a toy OS: Follow Operating Systems: From 0 to 1 or the OS Dev Wiki tutorials to write your first kernel.[2][4][5]

Go deeper with Linux: Use Understanding the Linux Kernel and Linux Kernel Development to explore real-world OS internals.[1][3][4]

Apply to Cyberdeck: Use the DIY Cyberdeck books and build guides to port or adapt your OS projects to portable hardware like Raspberry Pi.[6][7][8]

All of these resources are either free online or widely available in digital/print formats, and they align well with your interests in open-source, customizable, and affordable tools.
